A .env file is required with the following:

TOKEN: your discord bot token

CLIENTID: Your discord client id

MC_IP: This is the ip that the bot uses when fetching status's from a minecraft server

Example of a .env:

TOKEN=iodhooæwihdlouhawldughliawuygd

CLIENTID=91298729238729873918

MC_IP=MCSERVER.server.mc
